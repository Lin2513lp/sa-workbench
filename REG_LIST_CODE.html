实现说明
配置输出在 ahb_clk 域；新增时钟使能与 cpu_tpu_en 独立。保留位读0、写入忽略；RO 字段从状态输入直接读回，不增加状态锁存。
软复位按表中 W1P 属性及旧 RTL 实现；rpt_active_size 按描述使用完整32bit。寄存器rpt_cpt_error通过接口rpt_error_state[2:0]读回错误次数，字索引0x103、CPU偏移0x40C，返回{29'b0, rpt_error_state}。CTRL在输入LAST尚未读入就收到SA完成LAST时累计错误，同一次连续LAST只计一次，3bit计数到7饱和；rpt_error为次数非0的累计标志，复位或新START清零，关闭EN或DONE后保留。FIFO正常等待/气泡不报错，不增加寄存器地址。跨域状态应在接入前完成同步与一致性处理；本次寄存器端点不代替 CDC。
AHB 的合法地址检查已开放 0x105；AHB 的其他协议行为沿用当前代码。
