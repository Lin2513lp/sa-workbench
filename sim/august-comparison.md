# SA 当前波形与八月工作台对照

八月基准为 SA 工作台提交 `9b92a5308eb2c51ac270a35792394294bd551687`（2026-08-07），旧图直接从该提交的 `sim/int8.png` 提取，保留原始像素。当前图来自已经通过测试的当前 VCS FSDB，按 100% 显示比例重新用 Verdi 原生截图，没有重新设计或修改 RTL/TB。

| 对照项 | 八月工作台 | 当前版本 |
|---|---|---|
| SA_TOP 对外接口 | 原定 18 个 | 同名、同方向、同参数位宽的 18 个；额外 vector_in_vld / vector_in_last 已删除 |
| 波形信号 | 旧图为端口列表的一部分，时钟行在上方滚动区域 | 18 个对外端口全部列出，无内部信号、无额外总线切片 |
| 输入 VALID / LAST | 原阶梯输入驱动，最后一个阶梯拍给 LAST | 现有 VALID / LAST 标记 lane0 原始向量；内部恢复 PE 有效窗口，输入仍是逐路 Skew 数据 |
| 输出收集 | LAST 触发 IDLE/WAIT/OUTPUT；逐列保留历史结果，末拍保留所有完成列 | 零点前流式收集器；每列结果按各自有效标记输出，无效列补零，最终列的最后结果携带 LAST |
| 输出总线含义 | 后续拍仍含先前已完成列 | 后续拍中已经无效的列归零；不能把整条 dat_out 与八月版逐拍视为相同 |
| 内部 output_collector 接口 | 10 个端口 | 零点前已有的 13 个端口；当前不是八月原版收集器 |
| PE 与 SA_CTRL | 八月实现 | 两者 RTL 与八月一致；FP2FIX 保留后来两处已验证的小修正 |
| INT8 TB | 一组 A 阶梯输入，16×16，检查 16 列 | 沿用零点前驱动器：H/W=1、4、16；gap=0、3、20，共 9 任务、1008 个结果、330 个有效零值 |
| 当前图的片段 | 一次连续输入及其输出 | 当前细节图为最后的 16×16、gap=20 任务尾段；VALID 有空隙是测试主动插入的气泡 |
| 时间轴与数值 | 原始图约 0–406 ns，使用原八月随机输入 | 当前全部 9 任务约 0–6510 ns；输入/权重生成方式、任务及气泡不同，绝对时间与数据不可直接重合 |

**“保持原样”的参照必须说清楚。** 之前所说三个单元 TB 未改、输出结果/时序对照一致，参照的是零点前版本，不是八月整个项目。与八月逐文件比较，三个单元 TB、公共驱动器、Multi 包装及输出收集器等早已不同，具体清单见 source_comparison.json。不能据此声称当前 SA 与八月完全相同，也不能把当前所有模块接口说成与八月一字不差。

现有回归说明当前实现满足零点前流式结果约定：6 组 SA 顶层、3 个单元测试及严格 TOP smoke 均通过。108 任务逐拍对照也以零点前版本为参考，并不证明与八月逐拍等价。本次删除两根 SA_TOP 额外输入后，没有增加数值缓存或结果延迟；已有 VALID/LAST 的标记时序确有调整。

没有依据本次对照继续修改设计。若要恢复八月完整的输出协议与内部模块接口，那是额外的设计回退，会涉及当前 TOP 的流式联调，不能只通过隐藏波形或删两行端口完成。
